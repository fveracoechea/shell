# Domain Docs

This repository uses a single-context domain-document layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant ADRs under `docs/adr/` when they exist.
- If these files do not exist, proceed silently. Create them only when domain modeling resolves a term or a durable architectural decision.

## Use the glossary vocabulary

Use terms as defined in `CONTEXT.md` in issue titles, hypotheses, tests, and code. If a required concept is absent, reconsider whether the term belongs or identify it as a domain-model gap.

## Flag ADR conflicts

Surface any conflict with an existing ADR instead of silently overriding it.
